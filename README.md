# Belgian Waffle Co. - CCTV Maintenance & Expense Operations Dashboard

A real-time, interactive operations intelligence dashboard for **The Belgian Waffle Co.** (Bloombay Enterprises / VM IT Solutions) to track and optimize CCTV maintenance expenditures, repeat store issues, and month-on-month trends.

## 🚀 Live Demo & Access
- **Live Google Sheet Integration**: Synchronized with live CCTV Maintenance Google Sheet.
- **Standalone Web App**: Fully functional offline and online with zero build steps or server dependencies.
- **GitHub Pages Ready**: Can be served globally via GitHub Pages.

## ✨ Key Features
- **12-Month MoM Expense Trend**: Column visualization comparing all 12 months with dynamic High (Peak) and Lowest spend badges.
- **Multi-Select Checkbox Filters**: Filter by any single month, or multiple months (e.g. 2, 3, 4 months combined), multi-year, multi-city with search, and cost centre (Opex / Capex).
- **Repeat-Issue Stores Tracking**: Real-time identification of recurring store issues with risk prioritization (`CRITICAL 4+ Visits`, `HIGH 3 Visits`, `MEDIUM 2 Visits`).
- **Interactive Stores Audit Modal**: Searchable, sortable audit table for all repeat-issue stores.
- **1-Click Excel Exports**:
  1. `🔥 Repeat Issue Stores Report` (Includes action notes, root cause, assigned vendor/engineer columns).
  2. `🏪 Active Stores Summary Report` (Aggregated store spend, visit counts, and city breakdown).
  3. `📑 Full Maintenance Transactions` (All line-by-line sheet records).
- **Belgian Waffle Co. Brand Identity**: Custom dark mocha, waffle gold, caramel, and strawberry rose theme with the official company logo embedded.

## 🛠️ Tech Stack
- **HTML5 / CSS3**: Modern responsive layout with glassmorphism and custom mobile-ready design.
- **JavaScript (ES6+)**: Zero-dependency frontend architecture with CORS-free JSONP + CSV fetch fallback.
- **Chart.js & Plugins**: High-performance interactive data visualizations.
- **PapaParse**: Reliable client-side CSV parsing.
